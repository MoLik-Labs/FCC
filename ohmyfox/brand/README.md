# Oh My Fox identity

Oh My Fox is the name of the independent agent project; FCC remains the name of
its existing gateway. The mark in this directory is an original, editable SVG,
not a claim of trademark registration or affiliation with another agent.

- **Positioning:** a clear, user-directed coding assistant. Today only a Go
  read-only prototype and a transport-independent Rust core exist.
- **Voice:** direct, precise and honest about permissions, network destination,
  verification and unfinished work. Avoid unsupported superlatives.
- **Palette:** forest `#172723`, fox `#ed8a51`, cream `#f8eee1`, ear `#713f36`.
  The icon is decorative when accompanied by the name; use an empty alt there.
- **Names:** “Oh My Fox” in prose; `oh-my-fox` for the Rust executable;
  `OMF_` for environment variables. Do not rename FCC or imply the two are
  already integrated.
- The project follows the repository's [AGPL-3.0-only license](../../LICENSE).
  No separate trademark rights or legal clearance are asserted.
