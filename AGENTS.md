# Repository agent guidance

Read `docs/design/skill-workflow.md` for the requested design, workflow, Go and
systems skill sources, pinned revisions and restoration instructions. Consult
the relevant skills before implementation and review; select them by task. Follow the applicable guidance as a review aid, not as a
replacement for the user's instructions, accessibility, repository contracts or
security review. Do not enable third-party hooks or execute downloaded scripts
without reviewing them first.

FCC's Python server is the supported runtime; Go parity and Oh My Molik Rust
are experimental. Preserve remote/tunnel operation and existing streaming.
Do not claim features or performance improvements without verification. See
`docs/oh-my-fox/verification.md` and `docs/rewrite/00-master-plan.md` for current
limitations.
