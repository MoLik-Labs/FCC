INTEGRATION / EXPERIMENTAL

A small, read-only MCP server.

Let a trusted MCP client inspect a workspace using Molik over stdio. Build the Rust binary first, then replace both absolute paths in your client’s configuration. Client configuration formats may differ.

Trust matters. The client can read workspace files and may send them elsewhere. This is not a sandbox or a secret filter; there is no per-call approval or HTTP transport. Use a trusted client and workspace, and never expose the process on an unprotected network.

Supports MCP 2025-06-18 initialization, ping and two tools: list_files and read_file. It does not connect Molik to external MCP servers, run shell commands or edit files.

Setup, limits and verification →
CLIENT CONFIGURATION / EXAMPLE 
{
  "mcpServers": {
    "oh-my-molik": {
      "command": "/absolute/path/to/oh-my-molik",
      "args": [
        "mcp", "serve", "--workspace",
        "/absolute/path/to/trusted/project"
      ]
    }
  }
}
